# auto_dir_description

Robot description for **auto_dir**, generated by URDF Forge.
REP 103 conventions: Z-up, metres, kilograms, radians.

## Build

```bash
cd ~/ros2_ws/src && cp -r /path/to/auto_dir_description .
cd ~/ros2_ws && rosdep install --from-paths src -y --ignore-src
colcon build --packages-select auto_dir_description && source install/setup.bash
```

## Run

`ros2 launch auto_dir_description display.launch.py` shows the model in RViz with joint sliders.

| Target | Distribution | Simulator launch |
| --- | --- | --- |
| `jazzy-harmonic` | ROS 2 Jazzy · Gazebo Harmonic | `ros2 launch auto_dir_description gazebo_jazzy-harmonic.launch.py` |

## Layout

- `urdf/auto_dir.urdf.xacro`: the source of truth. `xacro auto_dir.urdf.xacro sim:=<target>` (default `jazzy-harmonic`).
- `urdf/auto_dir.<target>.urdf`: pre-expanded URDF per target, for tools that cannot run xacro.
- `sdf/auto_dir/`: standalone SDF model.
- `meshes/`: binary STL meshes.
- `config/controllers.yaml`: ros2_control controllers. `config/gz_bridge_<target>.yaml`: ROS <-> Gazebo topics.
- `worlds/`: an empty world with the physics, sensors, IMU, contact and force-torque systems loaded.

## Notes

- Mesh URIs use `package://auto_dir_description/...`. The launch files add the install share
  directory to the simulator's resource path so Gazebo can resolve them.
- Inertias were integrated over the mesh geometry for a solid of uniform density. Check any link
  the editor flagged as not watertight.
